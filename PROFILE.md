# We > Ultrarich

A free, non-commercial tool and public API that visualize extreme wealth inequality by comparing any wealth to ultrarich/billionaire/trillionaire wealth through four lenses: Duration Of Daily Spend, Height Of Stacked Money, Number Of Items Paid For, and Growth Of Compound Interest. All comparisons are deterministic arithmetic returning ready-to-quote figures, sentences, and them-vs-you ratios; no user data is collected.
